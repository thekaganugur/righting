## Question

Once the focused band capabilities are settled, specify the lightweight documentation-only routing protocol that composes them during ordinary agent work.

Apply [Define Righting's AI-oriented operating model](01-define-rightings-ai-oriented-operating-model.md). Decide:

- how onboarding tells an agent to orient from `righting.json` and `righting inspect --json`;
- the exact material-change trigger-to-capability routing table;
- how focused skills compose with `grilling`, `domain-modeling`, and approved-record updates;
- how an ordinary policy-compliant repair avoids unnecessary design interrogation;
- how transitional `righting-design-review` is deprecated and removed as focused skills land; and
- what each of README, `docs/operating-model.md`, onboarding references, skill descriptions/bodies, and the minimal managed `AGENTS.md` block owns without duplication.

The result is an implementation-ready documentation and skill-migration handoff, not a new orchestration skill.
