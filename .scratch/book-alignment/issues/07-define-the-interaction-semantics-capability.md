# Define the interaction-semantics capability

Type: grilling
Labels: wayfinder:grilling
Status: open
Blocked by: 03, 06

## Question

Define the focused band-3 `interaction-semantics` capability under the operating model established by [Define Righting's AI-oriented operating model](01-define-rightings-ai-oriented-operating-model.md).

Decide:

- which static relationships or mechanism clues deterministic tooling may report;
- which tests, configuration, infrastructure, or runtime observations count as external evidence;
- how `righting.json` represents an approved interaction declaration, acknowledged uncertainty, or non-applicability;
- the focused skill's investigation and escalation process;
- whether any adapter diagnostics are justified beyond the existing direct Manager-import prohibition; and
- how the capability catalog and `inspect --json` state that static evidence does not establish queued, publish/subscribe, or other runtime semantics.

End with an implementation-ready product, manifest, and skill contract. Righting must coordinate evidence without claiming its static tooling proved runtime behavior.
