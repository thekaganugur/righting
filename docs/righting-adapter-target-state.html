🛡️

Conformance remains the support gate

Shared classification does not replace native black-box testing. Every supported adapter must still prove dependency forms, coverage, classification, treatment, reporting, and claimed capabilities through its public native lint entry point.

Final architecture

Path B remains the architecture. The normalized JSON contract is the authoritative seam. righting/contract is a narrow, optional JS/TS reference interpreter that removes needless semantic duplication, while a private loader removes packaged plumbing duplication. Guardrail adapters continue to own everything genuinely native.

Proposed target-state artifact. Decisions reflected: authoritative normalized contract; classification-only reference interpreter; fail-closed version checks; immutable per-run snapshot; private packaged loader; adapter-owned diagnostics and capabilities; unchanged conformance obligations.
